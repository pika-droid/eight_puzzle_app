## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability in the 8-Puzzle Solver, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Please send an email to the project maintainers.

### What to Include

- A detailed description of the vulnerability.
- Steps to reproduce the issue (including any relevant code snippets).
- The version(s) of the project affected.
- Any potential impact or suggested mitigation.
